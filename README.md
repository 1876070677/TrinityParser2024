# Trinity Parser

가톨릭대학교 학생들의 수강 신청을 돕기 위해 만들어진 서비스입니다.

## 서비스 주소

**https://trinity.dobby.kr**

## 주요 기능

### Dashboard

수강 신청과 성적 관련 정보를 한눈에 확인할 수 있는 메인 화면입니다.

- **수강 신청 인원 조회**: 원하는 강의의 실시간 수강 신청 인원을 확인할 수 있습니다.
- **성적 조회**: 나의 성적을 빠르게 확인할 수 있습니다.
- **방명록**: 의견이나 문의사항을 자유롭게 남길 수 있습니다.
- **FAQ**: 자주 묻는 질문과 답변을 확인할 수 있습니다.

### About

트리니티 파서를 만든 제작팀에 대한 소개를 확인할 수 있습니다.

### Archive

가톨릭대학교 학생들이 직접 만든 다양한 웹 앱과 모바일 앱을 모아볼 수 있는 공간입니다.

## 주의사항

### 수강 신청 인원 조회 관련

수강 신청 인원 조회 기능을 사용하시다가 헷갈리는 부분이 있으시다면, **FAQ**를 먼저 확인해주세요!

FAQ에서도 해결되지 않는 문의사항이 있으시면 다음 방법으로 연락해주세요.
- **에브리타임** 덧글 또는 쪽지
- **방명록**에 글 작성

### 성적 조회 관련

아래의 경우에는 성적 확인이 불가능합니다.

- **성적 미리보기 기능**: 학교 측 조치로 인해 현재 사용이 불가능합니다.
- **강의 평가 미완료**: 강의 평가를 완료하지 않은 경우 성적 확인이 불가능합니다.

위 제한 사항은 학교 시스템 정책에 따른 것으로, 저희 서비스에서 해결할 수 없는 부분입니다. 양해 부탁드립니다.
